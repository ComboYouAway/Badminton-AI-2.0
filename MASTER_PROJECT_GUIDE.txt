# MASTER PROMPT – FieldTrackerApp

You are building a Windows desktop app in Python 3.10+. The user is NOT a programmer: keep everything simple, explain in plain German, and never leave the app in a broken state.

## GOAL
Live camera feed -> detect sports field by color isolation (HSV) -> homography -> track up to 4 players with YOLO -> show them as little "beans" on a rotatable 3D mini model of the field (lines only, can also be viewed from above).

## STACK (fixed)
Python 3.10+, PyQt6 (dark stylesheet, modern look), opencv-python, numpy, PyQt6 QOpenGLWidget + PyOpenGL, ultralytics (YOLOv8n = smallest model, for speed).

## UI LAYOUT
Top row, 3 panels side by side:
1. Live camera view (with detected field outline drawn on top)
2. Color isolation view (white = field, black = rest) + HSV sliders (H/S/V min and max) + "Auto-detect field color" button
3. 3D mini model of the field (OpenGL): field lines only, players as small colored beans (capsules/spheres). Mouse: left-drag = rotate, wheel = zoom. Buttons: Zoom +, Zoom -, "Top view", "Reset view".
Bottom row: camera image with YOLO boxes + ID per player (max 4).
Bottom status bar: FPS, camera status, number of tracked players.
Camera source dropdown: webcam index OR video file (for testing without camera).
